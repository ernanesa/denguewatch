# DengueWatch — desafio DIO .NET e MongoDB

Reimplementação educacional do zero, com dados sintéticos. O planejamento foi consolidado em **05/10/2026**; a aplicação deste checkout ainda não foi implementada.

**Documentação de planejamento:** o diretório `plan/` é local e está ignorado pelo Git (`.gitignore`), portanto não acompanha clones do repositório. Para publicar esta documentação, é preciso versioná-la e remover a entrada `/plan` do `.gitignore`.

A entrega DIO termina em B5 + G-DIO: cadastro e consulta integrados ao MongoDB real, testes e reprodução documentada em repositório próprio. Autenticação, produto V2, geolocalização, estatísticas, otimizações e deploy são evoluções posteriores.

Referência: [gabrielfaraday/dotnet-mongo](https://github.com/gabrielfaraday/dotnet-mongo). Links do material no arquivo [projetoNetMongo.md](projetoNetMongo.md). Fork é opcional. Os contratos modernos propostos não são compatíveis automaticamente com `/infectado` da referência.

Alvo: .NET (versão pendente de verificação). O planejamento previa .NET 11 RC, mas não há SDK .NET 11 instalado neste ambiente (máximo disponível: 10.0.302). Não há resultado de build, integração ou benchmark desta aplicação para declarar aprovado.
